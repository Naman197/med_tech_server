# Ayutrack Backend

The **Ayutrack Backend** is a RESTful API built using **Node.js**, **Express**, and **MongoDB**. This service powers the core functionality of the Ayutrack platform, which is designed to facilitate streamlined coordination between users and service providers in the healthcare or wellness sector.
